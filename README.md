# Dynamic Loan Amortization & Prepayment Model

An interactive financial modeling tool built in Microsoft Excel designed to simulate loan schedules and evaluate the financial impact of recurring prepayments.

## Key Features
* **Dynamic Amortization Schedule:** Computes monthly principal and interest breakdowns across the full life of the loan.
* **Prepayment & Early Payoff Analysis:** Evaluates how extra monthly payments reduce overall loan term length and total interest paid.
* **Executive Summary KPI Dashboard:** Real-time summary metrics tracking expected payoff dates, time saved, total extra contributions, and net interest savings.
* **Automated Terminal Adjustments:** Reconciles the final payment period to account for rounding adjustments and premature balance resolution.

## How to Use
1. Download the `.xlsx` file from the repository.
2. Open directly in **Microsoft Excel desktop** (viewing in third-party viewers or web previews may break dynamic array formulas and custom cell references).
3. Input your loan parameters (Loan Amount, Annual Interest Rate, Payment Frequency, and Extra Payment) into the light-blue input cells.
